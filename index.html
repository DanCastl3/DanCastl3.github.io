01
Sistema de Gestión de Aprendizaje Seguro (LMS) Nov 2025
  • Plataforma académica full-stack con 3 roles (Admin, Profesor, Alumno), API RESTful con +25 endpoints en Express.js y auditoría completa en MySQL con triggers por INSERT, UPDATE y DELETE.

  • Gestión de archivos con Multer, prevención de path traversal, respaldos automáticos vía mysqldump y pipeline CI/CD con GitHub Actions.
